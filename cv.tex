\section*{Research Interests}
My research focuses on building reliable programming systems by bridging formal methods and agentic AI:
\begin{itemize}
	\item \cvemph{Verified AI-Assisted Programming:} Building programming systems in which AI agents generate code together with formal proofs of correctness, enabling safe and reliable automated software development.
	\item \cvemph{Specification Languages for Trustworthy Intent Formalization:} Developing specification languages that support stepwise translation from natural language to formal specifications, narrowing the gap between the two and making intent formalization trustworthy.
	\item \cvemph{Neuro-Symbolic Agent Safeguards:} Preventing errors and unsafe actions in agentic workflows through runtime verification, ensuring the safety of AI agents.
\end{itemize}
